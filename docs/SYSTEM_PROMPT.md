# 系统提示词维护

Vue/FastAPI 聊天入口的基础系统提示词统一保存在 `agent/prompts/system.md`。
文件内容会整体作为提示词读取，编辑时无需添加 Python 字符串或转义字符。

## 加载方式

- 后端启动时按项目绝对路径读取 UTF-8 Markdown 文件，修改后需要重启后端。
- 文件不存在、无法读取或内容为空时，后端会明确报错，不会静默使用另一份默认提示词。
- Vue 前端不再保存或发送基础提示词，普通和流式聊天都使用后端读取的版本。
- API 仍支持显式传入 `system_prompt` 覆盖基础提示词；未传或为空时使用 Markdown 默认值。
- 每次请求仍在基础提示词后追加本次会话的数据目录、错误恢复规则和 RAG 规则。

## 分析输入的来源

默认数据目录仅包含当前会话的上传和输出目录，不再向模型默认提供 benchmark 目录。
文件型 MCP 工具在执行前检查输入路径，只接受当前会话已有文件或用户消息中明确指定且实际存在的路径。
助手自行编造的路径、其他会话路径及服务器样例不会因为出现在模型回复中而获得使用资格。
同一会话的历史上传和生成结果可以继续作为后续工具输入，无需每轮重新上传。
没有文件和地点依据时，提示词要求先向用户澄清，不得自行假定城市、经纬度或当前灾情。
该路径检查不是操作系统级沙箱，也不替代对模型事实性和地点判断的约束。

该文件约束第一阶段的主体分析与完整 `<Conclusion>` 回答。
第二阶段多模态 review、RAG 证据核验及各 MCP 工具说明保持各自的独立职责，不在本次迁移中合并。
数据库保存的旧会话提示词是历史记录；后续标准前端请求使用当前后端加载的 Markdown 版本。
