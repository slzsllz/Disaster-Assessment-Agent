# Agent 工具接入筛选

本仓库的 MCP 服务合计注册 108 个工具；注册成功不等于适合默认交给灾害评估 Agent。
默认清单见 `agent/tool_policy.py`：11 个服务、39 个工具。后端只启动清单中的服务，
并在创建 LangGraph Agent 前按工具名再次过滤；路由器也只能看到这 39 个工具。

筛选标准：直接服务于灾害识别、遥感预处理、灾前灾后变化和影响量化；输入输出可以
解释为明确的遥感分析任务；当前部署环境具备必要运行依赖。通用算术、列表处理、
重复统计函数、缺少依赖或外部密钥的功能，不进入默认清单。

主要排除项：

- `PestDetection`：`ultralytics` 未安装，模型权重虽在本机但无法执行。
- `LandslideSegmentation`：`h5py` 未安装，无法读取所需 HDF5 输入。
- `GeoContextQuery`：当前未配置 ArcGIS API 密钥，在线地理查询不能作为可靠默认能力。
- `GeoAI` 的 DINOv3 特征/相似度工具：侧重通用特征研究，且权重和运行成本较大；
  保留更贴近灾害制图的目标检测与水体语义分割。
- `Statistics` 中的加减乘除、列表运算、大量重复批处理指标，以及 `Inversion` 中
  与当前灾害评估主线无关的专门微波/海冰反演：避免工具选择噪声。

此筛选不等同于逐工具精度验证。新增工具前，应补齐依赖/密钥，使用对应样例数据验证
输出和地理参考信息，再加入 `CURATED_TOOLS_BY_SERVER`。
