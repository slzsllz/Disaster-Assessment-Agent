> 调研时间：2026-08
> 目的：为本项目（Disaster-Assessment-Agent，LangGraph+MCP 多工具灾害遥感评估智能体）撰写学术论文提供文献基础、相关工作定位与研究切入点。

---

## 一、本项目技术定位（用于论文对比与贡献声明）

通过阅读源码，本项目可概括为：

| 维度 | 本项目的实现 |
|------|--------------|
| 智能体框架 | LangGraph ReAct agent（`create_react_agent`）+ MCP 多服务器（`MultiServerMCPClient`） |
| 大语言模型 | Qwen3-235B / DeepSeek / GPT-5（可切换，openai_chat / deepseek_chat） |
| 工具集（MCP Servers） | Perception、GeoAI、Index（指数）、Inversion（反演）、DamageAssessment（震害）、FloodSegmentation（洪水）、FireBurnedAreaChange（过火变化）、LandslideSegmentation（滑坡）、OilSpillSegmentation（溢油）、GeoContextQuery（地理上下文）、Analysis（统计分析）、PestDetection、AlgalBloomDetection |
| 下游深度学习模型 | Sen1Floods11（洪水）、Xview2（震害）、Landsat-L4S（滑坡）、CBDNet（溢油）、YOLO（虫害）、NDCI（藻华）、FLOGA 等 |
| 特色能力 | 多轮对话、SSE 流式、PDF 灾情报告、bbox/legend/几何矢量化输出、PostgreSQL+PostGIS 持久化、跨任务错误记忆（error_memory）、自动规划（autoplan 变体）、答案与产物审查（review_answer_and_artifacts） |

**相对已有工作的差异化卖点（可写进 contribution）**：
1. **多灾种覆盖**：单一智能体统一调度洪水/震害/滑坡/溢油/虫害/藻华等多类灾害评估工具，而非单一任务。
2. **MCP 标准化工具接入**：以 MCP 协议封装地理空间/深度模型工具，契合当前 Agent 生态标准。
3. **工程化闭环**：会话级状态隔离、流式交互、可视化图例与矢量结果回传、PDF 报告生成、数据库持久化——面向"可落地部署"而非仅研究原型。
4. **跨任务错误记忆 + 结果审查**：把前序任务踩过的坑复用到后续任务，并二次审查模型答案与产物，提升可靠性。

## 三、研究切入点 / 潜在贡献（供论文定位）

综合调研，本项目最可能产出论文的差异化角度：

1. **多灾种统一调度 vs 单一灾种智能体**：既有 RS-Agent / Change-Agent / RescueADI 多为单一或少数任务；本项目在一个 ReAct 循环中统一调度 13 类灾害/分析工具，可论证"多灾种统一入口"的工程价值与性能。

2. **MCP 标准化 + 工程化闭环**：当前多数相关工作是研究原型、缺乏可部署接口；本项目提供 SSE 流式、会话隔离、矢量/图例回传、PDF 报告、数据库持久化，可定位为"面向实战部署的灾害遥感智能体"。

3. **跨任务错误记忆（error_memory）+ 结果审查（review）**：这是本项目的潜在亮点，与 RSMeM（记忆演进）可比但实现更简单直接；可做消融实验证明其提升工具调用成功率与答案可靠性。

4. **评测缺口**：可借用 ThinkGeo / GISAgentBench / GeoDisaster 的评测思想，为本项目设计一套"多灾种遥感任务"基准，或对现有基准给出本项目的表现，形成"评测 + 系统"型论文。

## 四、建议论文结构（可参考）

1. **Introduction** — 灾害应急对快速遥感解译的刚需；LLM Agent 为"自然语言→自动化解译"提供新范式；现有工作痛点（单灾种、研究原型、缺乏闭环）。
2. **Related Work** — 按 A/B/C/D 四类组织。
3. **Method / System Design** — 总体架构（LLM + ReAct + MCP 工具集 + 下游模型）；工具封装与自动选择；多轮会话与流式；错误记忆；结果审查；报告生成。
4. **Experiments** — 多灾种场景用例（洪水/震害/滑坡/溢油）；评测指标（工具调用成功率、任务完成率、解译精度、推理时延）；与 RS-Agent 等基线对比；消融（有无错误记忆、有无审查）。
5. **Discussion** — 失败模式、幻觉与误用风险、可扩展性。
6. **Conclusion**
